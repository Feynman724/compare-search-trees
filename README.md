# Compare Search Trees

一个可离线打开的 16:9 HTML 演示，说明题目要求的五种搜索树、三组插入/删除序列及运行时间比较。直接打开 `index.html`；左右方向键切页，`F` 全屏。第 7–8 页可选场景、播放、单步、跳到插入完成或拖动进度；`Space` 播放/暂停。网页不显示讲稿，演讲者使用独立的 `逐页讲稿.md`。

## 演示结构

1–4 页交代问题、树的维护方式、复杂度和计时方法。5–6 页展示七种规模（1,000–100,000）的实测曲线。7 页让 BST、AVL、Splay、红黑树、B+ 树同步执行同一操作；8 页放大比较结构，并把教学示例与报告计时并列说明。9 页总结结论和局限。

动画使用 9 个键，分“定位”和“更新”两帧。BST、AVL、左倾红黑树与 B+ 树有独立的 JavaScript 教学模型；Splay 复用自顶向下伸展跟踪引擎。B+ 动画采用节点容量 4，以展示分裂、借位和合并；原 C 实验采用容量 32。动画中的树形、层数及维护动作不等于原报告的耗时测量。

`data.js` 的数值来自用户提供的 `compare-search-trees.pdf` §3.3（2026-10-03），为三次运行的插入加删除总时间中位数。原实验报告和 C 代码属于另附的课程提交资料，未包含在本网页仓库。网页图表不会重新运行基准测试；五种树使用同一试验输入的公平性由原 C 程序负责。

## 检查

```sh
node experiment-tests.js
node trace-tests.js
```

`experiment-tests.js` 检查三组规定序列和 80 组随机完整插入/删除周期：键集合、BST 顺序、AVL 高度约束、红黑树颜色与黑高、B+ 占用率/分隔键/叶链，以及最终清空。`trace-tests.js` 验证 Splay 跟踪引擎的混合操作和节点身份。浏览器打印可输出全部九页；动画页打印当前状态。
