# Compare Search Trees

直接双击 index.html 即可离线演示，无依赖、无构建、无网络请求。建议桌面 Chrome / Edge，F 进入全屏，Esc 退出；左右方向键切页。讲稿单独保存在 `逐页讲稿.md`，网页不显示讲稿。动画页用 Space 播放或暂停，也支持前后单步、重播和速度调节。BST 用珊瑚红、Splay 用青绿色标注访问路径；实心节点是当前操作位置，浅色节点是已访问节点。图例可切换曲线，悬停数据点查看毫秒数。

数据来自 compare-search-trees.pdf §3.3，2026-10-03；全部为三次运行的插入加删除总时间中位数，未生成任何替代测量。原实验报告与 C 代码保存在课程提交资料中，未包含在本网页仓库；动画中的 JavaScript BST 与自顶向下 Splay 是独立教学实现，不是 C 代码的逐行回放。

文件：data.js 保存实验数据；algorithms.js 执行树操作和事件快照；app.js 管理 SVG、图表、幻灯片；style.css、comparison.css 和 polish.css 控制排版与动效。

第 1–4 页依次明确问题、结构差异、理论预期和实验设计；第 5–6 页给出实测结果；第 7 页使用已有节点访问量说明 BST 退化，树高按节点层数定义。第 8–9 页由 trace-engine.js 实现完整 BST / 自顶向下 Splay，comparison.js 和 comparison.css 负责同步回放和临时树可视化。动画规模为 7，实验规模为 1000–100000，两者时间不混用。

第 8 页：升序插入，两棵树形成方向相反的链；Splay 此时无旋转。第 9 页有三个可切换场景，均从空树开始、插入全部后删除至空树：升序插入/升序删除、升序插入/降序删除、固定乱序插入/删除。支持“从删除开始”“下一操作”、进度拖动、前后单步、播放暂停、重播和速度调节。离开页面自动暂停，重入自动复位。

Splay 动画展示真实比较、zig-zig 旋转、L/T/R 临时树、重组、移除根、伸展左子树最大值及接回右子树。节点以键为稳定身份，重组不交换标签。BST 双子节点删除使用后继节点移接，与报告的后继键替换具有相同集合语义，但指针写入次数不相同。

第 8–9 页采用统一的键比较计数：三路比较器每次调用计 1，包括 Splay 对孩子的 zig-zig 检查。旋转次数单列；指针写入计显式根、子指针及临时根赋值，排除节点初始化。均为从空树开始的累计值，“从删除开始”保留插入阶段计数。曲线采用固定纵轴，只在操作完成时增加数据点，展示累计比较量，不是毫秒，也不等于原 C 实现指令数。一般 Splay 均摊界不代表升序删除每一步都是常数时间；随机小样本不能证明实测排名。

运行 `node tests.js` 和 `node trace-tests.js` 进行算法与数据测试。后者验证 10000 次混合操作、集合结果、有序性、稳定节点身份、临时树无重复节点、完整清空和有序场景反差。浏览器打印可输出全部十页，建议横向、自定义纸张 16:9、关闭页眉页脚。动画打印的是当前状态，可先选择需要的步骤。

演示建议：在第 5–6 页先说“现象”，第 7–9 页再用动画解释“原因”。第 8 页观察同为链状时 BST 与 Splay 的访问路径；第 9 页依次切换三组操作，先看当前操作提示，再看树形与累计比较曲线。动画中的 7 个键仅用于说明机制，不是报告的计时输入。

本版逐页精修了标题层级、页码、图表容器、实验步骤、树形面板和结论页。讲稿与画面操作提示仅保存在独立文件 `逐页讲稿.md`。
